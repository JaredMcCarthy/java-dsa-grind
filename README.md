# java-dsa-grind ☕

Mi laboratorio de **estructuras de datos y algoritmos** en Java en la chillo.

Aquí no hay código perfecto. Hay código que escribí, rompí, arreglé
y entendí, eso es el punto.

---

## Qué hay aquí

Todo lo que practico para la clase de Estructura de Datos y Algoritmos.

- Ejercicios y problemas de práctica
- Exámenes
- Un proyecto por cada tema: listas, pilas, colas, recursividad, hash, encriptación
- Una carpeta con 30 ejercicios que uso para practicar Java porque la carrera lo usa bastante.

Cada carpeta es un tema. Cada tema tiene su `src/`.

## Cómo usarlo

1. Clona el repo
2. Abre la carpeta que quieras en IntelliJ
3. Correlo

## La regla del repo

la unica regla es que no acepto contribuciones porque es un repo de practica.
